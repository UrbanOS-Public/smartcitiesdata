# estuary Release Notes

## 0.11.21 (pending release — not yet tagged)
- Added support for multiple datasets per ingestion and an ingestion field selector
- Dead letter queue messages now include the ingestion ID and handle error reasons more safely
- Enabled XML request bodies for HTTP POST
- Added required extraction fields and updated transformation name/type handling
- Upgraded Trino and multiple dependencies, including fixes for known vulnerabilities in Node packages
